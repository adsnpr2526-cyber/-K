โปรแกรมคำนวณค่า K และออกรายงานแนบท้ายสัญญา (ตามหลักเกณฑ์ มติ ครม.)

1. ข้อมูลสัญญาและโครงการ

2. ตั้งค่าหลักเกณฑ์เงื่อนไขการปรับราคา ( Threshold / Condition )

* สำหรับเกณฑ์ 4%: ค่า K อยู่ในช่วง 0.96 - 1.04 จะไม่มีการปรับราคา / เกิน 1.04 ชดเชย (K - 1.04) / ต่ำกว่า 0.96 หักคืน (0.96 - K)

3. รายการงวดงานก่อสร้างที่ขอปรับราคา (สามารถเพิ่มได้หลายรายการ)

ลำดับ รายการงาน / ค่างวดงาน ค่างวดงาน A (บาท) สูตรการคำนวณที่ใช้ จัดการ

4. กรอกดัชนีราคา (Indices) สำหรับสูตรที่ใช้งาน
